Scherrer Calculator

The Scherrer equation relates the broadening of a diffraction peak to the size of the crystalline domains: the smaller the crystallite, the broader the peak.

D = Kλ / (β cosθ)

Peak data

K ≈ 0.9 is the most common value (0.89 for spheres, 0.94 for cubes). If you know the instrumental broadening, it is subtracted in quadrature: β² = βmeas² − βinst².

Above ~100 nm the size broadening is very small and the result is not reliable.

Several peaks and Williamson–Hall analysis

Scherrer assigns all the broadening to size. The Williamson–Hall method separates size (D) and microstrain (ε) using several peaks: β cosθ = Kλ/D + 4ε sinθ. The λ, K and instrumental values above are used.
